Reglas de uso

El color nunca va solo. Todo estado lleva ícono y palabra: Completado, Pendiente, Falló.
El ámbar es escaso. Solo estrellas, racha, niveles y el punto "por hacer". Nunca botones ni texto pequeño encima.
El verde tinte es "tu dinero está aquí". Se reserva para mostrar dónde espera el dinero.
Aviso ≠ acento. Aviso es café anaranjado (#9A4D00), acento es ámbar; así "pendiente" no se confunde con "tienes algo que hacer".
Oscuro no es negro puro. Fondo verde muy oscuro, sin brillo neón; la elevación se marca aclarando la superficie.
